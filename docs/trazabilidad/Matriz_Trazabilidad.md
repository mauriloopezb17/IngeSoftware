# **Matriz de Trazabilidad Bidireccional**

**Versión:** 1.1 (alineada con el SRS v1.1 y la versión 2.0 del sistema) · **Historia Jira:** PAR-176

Mapeo bidireccional que conecta cada requisito del [SRS v1.1](../srs/SRS_v1.1_ISO29148_Parroquia.md) con su fuente de elicitación, sus historias en Jira, el componente del [modelo C4 v2](../arquitectura/Arquitectura%20C4.md) que lo implementa, el [diagrama UML](../uml/README.md) que lo describe, los archivos de código principales y las pruebas automatizadas que lo verifican.

**Convenciones:**
* Las rutas de código y de pruebas son relativas a la raíz del repositorio. «Integración» = `backend/tests/integracion/`; «Unitaria» = `backend/tests/unit/`; «Frontend» = pruebas de Vitest en `frontend/src/`; «E2E» = `frontend/e2e/` (Playwright, contra la API real con PostgreSQL y Redis).
* Los componentes usan los nombres del C4 v2: contenedores (SPA web, API REST, Base de datos, Caché, Oracle Cloud Object Storage + CDN) y componentes del C3 dentro de la API REST (`API REST › nombre`).
* Estado: Implementado / Implementado parcialmente / Pospuesto (fuera de la v2.0) / Planificado / Fuera de alcance.
